# Tem’s cozy Den illustrations

Eighteen feature illustrations use the creator-approved character study, expression atlas and inhabited punk-science Den direction. Generated with the built-in image tool; exact prompts are preserved in `PROMPTS.json`, final checksums in `MANIFEST.json`.

These are conceptual illustrations, not screenshots, measured diagrams, permission matrices or evidence that a feature has passed validation. In particular the TUI scene’s drawn monitor is illustrative; use the CLI reference and actual TUI for supported controls. RBAC has Admin and User roles; tool icons are conceptual, not a permission grant table.

Character construction, reference priority and generation/review workflow: [art direction](../../docs/ART_DIRECTION.md) and [face/body study](../../docs/TEM_CHARACTER_EXPRESSIONS.md). Historical artwork remains in Git history and historical reports.
