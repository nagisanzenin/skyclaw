01 / THE PREMISE

A moment of intelligence.
A continuing existence.

Temm1e begins with an architectural assumption: the language model provides reasoning, intelligence and verdicts, one API call at a time. The harness supplies the continuing structure around those moments.

A call can produce a plan. It does not, by itself, preserve that plan through a reboot, remember which actions already happened, or decide when to return to unfinished work. Those responsibilities live somewhere outside the call. In Temm1e, they are the subject of the project.

What must we build around a reasoning model so that something continues to exist between its calls?

The creator’s ambition is to make Tem an entity: a persistent presence with memory, a relationship with its environment, and continuity of action. Computer use, native browser support and Perpetuum’s temporal machinery all follow from that ambition. They are parts of the same attempt.

“AGI-oriented” describes the direction of the architecture. As reasoning models improve, the surrounding system should be able to carry more capable intelligence forward through time. Temm1e does not establish that AGI, consciousness or personhood has been achieved. Its engineering can be examined without settling those questions.

WORKING DEFINITIONHere, an entity means a system whose memory, actions and commitments have continuity across individual calls. The deeper philosophical interpretation remains open.
02 / EMBODIMENT

A world to inhabit.

Human work happens in a continuing environment: a browser tab, a repository, a document, a conversation. Tem needs access to that environment and ways to observe how its actions change it.

Prowl provides browser interaction and dedicated profiles that can retain authenticated sessions. Gaze extends action to the desktop through screenshots and input. Shell, file and Git tools let Tem work directly with code and artifacts. The useful common property is an action followed by an observation that can enter the same continuing history.

Human-like computer use is one route into that world. APIs and terminals remain useful routes too. The model chooses among the available tools; the harness manages permissions, records and execution. A click is evidence that input was attempted. The resulting application state is what helps establish whether the action worked.

This distinction matters for identity as well. A familiar voice is part of Tem’s character, but durable state does the engineering work of continuity. Model selection can change while the running CLI or server retains its state. The result is a concrete property to inspect, rather than a claim that one model has become a permanent self.

03 / THE MATHEMATICS

Continuity has
quantities worth thinking about.

How quickly should a memory fade? How much should repeated use reinforce a lesson? How much evidence is enough to trust a result?

The mathematics is part of Tem’s design language. It makes these choices explicit: units can be checked, assumptions challenged, thresholds adjusted and implementations compared. Some components use established statistical methods. Others use deliberately chosen heuristics. Their roles differ.

λ / MEMORY

Forgetting as a change in attention.

s(t) = Ieff e−λΔtIeff = clamp(importance + recall boost, 0.1, 5.0)

λ-memory scores a memory using the hours since its last access. As the score falls, its representation can move from full text to a summary, essence or recall reference. Under pressure, the fidelity thresholds rise. The active context becomes selective while stored material can remain available for recall.

Open the equation: units, half-life and limits

For λ > 0, the score’s half-life is ln(2)/λ. At λ = 0.01 per hour, that is approximately 69.3 hours, or 2.89 days, while effective importance is held fixed. Recall changes both access time and potentially the boost, so a whole memory’s trajectory need not be a single uninterrupted decay curve.

This is a relevance policy, not a biological model of forgetting or a factual-confidence score. Lower context visibility does not promise indefinite archival retention. The token budget and current storage policy still matter.

β / LEARNING

A lesson has more than a timestamp.

V = αα + β · e−0.015d · [1 + 0.3 ln(1 + u)]

Learning artifacts combine a Beta-distribution mean for quality, recency in days, and logarithmic reinforcement from applications. The logarithm gives repeated use diminishing marginal influence. The decay term has a half-life of roughly 46.2 days.

Open the equation: how belief enters the score

Given model-provided confidence c, the initial parameters are α = 2 + 3c and β = 2 + 3(1 − c). For c between zero and one, the initial mean stays between 2/7 and 5/7. That keeps one model verdict from immediately becoming certainty.

The product is a ranking heuristic. A prior seeded by a model is not independent evidence, and use counts measure exposure rather than demonstrated benefit. A higher score does not establish that a lesson improves outcomes.

t / PERPETUUM

Time needs a denominator.

p̂ = a + 1n + 2Beta(1, 1) smoothing of recorded activity

Perpetuum estimates activity for matching local weekday/hour slots over the previous 28 completed local calendar days. Here a counts active slots and n counts eligible slots after the first recorded day. With one active slot out of four eligible slots, the estimate is 2/6—not certainty.

Open the equation: missing observations matter

No eligible slots returns the prior mean, 0.5. The current implementation counts missing slots as inactive after recording begins; it does not have a complete exposure model distinguishing every offline period from inactivity. Existing UTC buckets also make non-whole-hour timezone offsets approximate. This estimates recorded behavior, not the probability that a person or service was actually online.

S / MANY TEMS

Cooperation through local signals.

S = Aα Uβ (1 − D)γ (1 − F)δ Rζ

Hive scores a ready task for a worker using affinity, urgency, difficulty, failure and reward signals. Exponents control their influence. This is the appeal of the swarm idea: coordination can emerge from shared signals and local choices.

Open the equation: a priority score, with tradeoffs

The implementation floors affinity, urgency and reward at 0.001, and clamps difficulty and failure into [0, 0.999]. These choices prevent zero factors at the upper boundary for ordinary positive exponents. They are policy decisions. The score does not prove optimal scheduling, fairness, or a speedup over one worker. Dependency checks and task claims are separate responsibilities.

z / EVIDENCE

A perfect sample still has uncertainty.

L = p̂ + z²/(2n) − z√[p̂(1−p̂)/n + z²/(4n²)]1 + z²/n

Eigen-Tune’s statistical toolkit includes a Wilson interval for a binomial proportion. Thirty successes out of thirty trials yields a lower bound of about 0.819 at 99% two-sided confidence. A perfect observed score is still a small sample.

Open the equation: what the interval can establish

Here p̂ = k/n and z is the standard-normal critical value for the chosen two-sided confidence. The checked implementation rejects zero trials, impossible counts and invalid confidence. The interval assumes suitable binomial observations; it does not make model agreement a ground-truth label or fix correlations between related tasks.

Λ / SEQUENTIAL TESTING

Sometimes the right verdict is “not yet.”

Λn = Σ [xi ln(p₁/p₀) + (1−xi) ln((1−p₁)/(1−p₀))]

The sequential probability ratio test accumulates evidence between two fixed success-rate hypotheses. It can stop when an evidence boundary is crossed. Reaching the sample cap without crossing either boundary returns Inconclusive.

Open the equation: boundaries and assumptions

The upper boundary is ln((1−β)/α); the lower is ln(β/(1−α)). These use α and β as error targets, distinct from the Beta-distribution parameters above. Classical error-control arguments depend on the test’s assumptions, including independent Bernoulli outcomes and fixed hypotheses. They are not blanket guarantees about an adaptive agent.

Unknown must survive composition.

¬? = ?    T ∧ ? = ?    F ∧ ? = F

Witness uses three-valued composition for verified, failed and inconclusive checks. Missing evidence cannot turn into a pass just because a criterion was negated. Empty or entirely advisory check sets also remain inconclusive under the explicit verification policy.

This is a small piece of logic with a large consequence: a verdict can retain what the system does not know.

04 / RELIABILITY

The process can stop.
The history should survive.

The ambition behind Perpetuum is an agent that remains available and can return to work around the clock. Real machines reboot. Credentials expire. Network requests end ambiguously. Continuous operation therefore needs a companion property: recoverable continuity.

Temm1e v6 strengthens scoped conversation storage, saved final replies, resource ownership and cancellation. These are the details that let a later turn distinguish completed work from an interrupted attempt. An uncertain external send must not simply be replayed as if nothing happened.

The model supplies a semantic judgment. The harness must still enforce mechanical constraints: who owns a task, which profile it belongs to, whether a budget is known, and which effects have evidence. A model saying “done” cannot substitute for that record.

THE OPEN ENGINEERING WORKFull durable autonomous pursuit—including comprehensive task leases, reconciliation and child-task lineage—is not complete. v6’s recovery improvements do not amount to a guarantee of uninterrupted or exactly-once execution.

There is a behavioral question too. A persistent entity needs to know when to act, reconsider, ask, rest or stop. Indefinite activity without that judgment can become expensive repetition. Reliability and restraint belong in the same design.

06 / THE HORIZON

An unfinished question.

Temm1e’s playful character is an expression of the project’s ambition: intelligence should have somewhere to live, work, explore and return to. The cozy Den is the visual version of that idea. The engineering version is a history that remains coherent as calls, models and processes change.

There is still a substantial distance between persistent records and coherent agency. Which memories should survive contradiction? When does an old goal stop deserving attention? How can continuity be evaluated across weeks rather than isolated tasks? How much autonomy should depend on evidence accumulated in one particular environment?

These are the questions Temm1e is being built to explore. More capable reasoning models will make the questions more consequential. The work around those models already matters.
