Work is active on `codex/modernize-temm1e-research`. Baseline: `da503c0`; research: `a62e0a9`. This is an implementation checkpoint, not a release or a claim that modernization is complete.

## Ninth implementation checkpoint (streaming transport)

The TUI now observes real foreground text from OpenAI-compatible providers, including Z.ai coding plans, when `agent.streaming_enabled` is enabled. A request ID scopes previews; final or failed responses clear provisional text. Tool arguments are assembled by index and validated as complete JSON objects before dispatch. UTF-8 survives arbitrary network splits, SSE framing supports CR/LF/CRLF, and malformed/truncated streams return explicit errors. Cumulative usage snapshots are retained once, including trailing cache usage. Missing totals are marked unknown. Undocumented `stream_options` are not sent to arbitrary compatible endpoints.

The renderer buffers deltas and renders once per UI frame; provisional previews have a 256 KiB cap with a visible limit notice. Final responses remain authoritative. The unused stream sender whose receiver was immediately dropped and old parser-only tests were removed. The TUI smoke test now requires a final response instead of accepting an interim acknowledgment, with optional `--require-stream` validation.

This is a connection check, not a latency benchmark. Native Anthropic, Gemini and Codex Responses observer adapters remain unfinished and use their ordinary completion paths; this checkpoint does not claim streaming parity across all providers. Steering and full TUI product validation remain open.

## Tenth implementation checkpoint (native Messages streaming)

Anthropic Messages now uses the same bounded SSE byte transport as compatible Chat Completions. Its decoder matches deltas and stops to actual block indices instead of a last-tool stack, preserves response IDs, merges cumulative usage fields, and normalizes additive cache input once. It requires `message_stop`, rejects malformed tool JSON and unfinished blocks, and propagates stream errors. Unknown extension events are tolerated; private thinking is not displayed as the answer. Server-side tools require a separate result/history adapter and fail explicitly rather than silently losing their execution state. Signed extended-thinking history, Gemini and Codex Responses native observer support remain open.

Production-decoder fixtures cover interleaved block indices, malformed JSON, unknown events and usage updates. Real HTTP fixtures cover byte-fragmented Unicode, normalized cache counts and a connection that closes after a stop reason but before `message_stop`; the latter correctly fails. Provider tests and all-feature/all-target clippy pass. No live Anthropic account request was made for this checkpoint.

## Eleventh implementation checkpoint (context handoffs)

The journal-enabled runtime now compacts completed history into validated, immutable handoff generations, with original user/system messages retained verbatim, tool-result provenance, scoped original-text recall, and no secondary hidden history-dropping pass. Generation commits occur only after the final assembled request fits its estimated budget. Summarizer requests use the selected model, preserve atomic tool groups, have bounded output and one corrective validation retry, and count returned usage. Visible tool order is deterministic; dispatch now enforces the actual filtered tool set. The TUI exposes a Compacting phase.

See `CONTEXT-IMPLEMENTATION.md` for the precise algorithm, source files, acceptance results, unsuccessful live fixture and fixture correction, and remaining limits. Three consecutive handoffs, raw-history preservation, stale-write rejection, failed replacement, source recall, and tool-filter enforcement have direct tests. Live Z.ai fixture v3 preserved the latest correction and an oldest-only constraint. This does not yet provide full restart continuity when legacy session loaders restore only a tail; that and exact tokenization/native cache management remain open.

Validation for the handoff checkpoint: the agent/TUI run passed 889 tests with zero failures and three ignored across 15 suites before the final storage changes. The final five-test compaction integration suite passes, including content-addressed source reuse, legacy inline-handoff compatibility, and corruption detection. Formatting, diff checks and workspace all-feature/all-target clippy pass. These overlapping counts are not additive.
